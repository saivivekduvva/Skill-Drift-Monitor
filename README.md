# 🎓 Academic–Industry Skill Drift Monitor

An interactive **Streamlit-based analytics platform** that identifies **curriculum gaps** by measuring how well **academic syllabi align with current industry job requirements** using **Natural Language Processing (NLP)** techniques.

This project helps institutions, educators, and curriculum designers **quantitatively evaluate skill relevance** and make **data-driven curriculum decisions**.

---

## 📌 Overview

In rapidly evolving technical fields, academic curricula often lag behind industry expectations — a challenge commonly referred to as **skill drift**.

The Academic–Industry Skill Drift Monitor addresses this issue by:
- Comparing academic syllabus content with real-world job descriptions
- Measuring semantic alignment using NLP-based similarity analysis
- Highlighting curriculum strengths and critical gaps
- Presenting insights through interactive visual dashboards

The platform is suitable for **institutional audits, academic research, hackathons, and demonstrations**.

---

## 🎯 Objectives

- Detect gaps between academic curricula and industry demands  
- Quantify alignment using interpretable similarity metrics  
- Identify high-risk curriculum areas  
- Provide actionable insights through visual analytics  
- Support both demo exploration and institutional syllabus evaluation

## ✨ Key Features

- **NLP-Powered Skill Matching**  
  Semantic comparison between syllabus content and job descriptions

- **Dual Operation Modes**
  - **Demo Mode** with preloaded synthetic academic data  
  - **Institution Audit Mode** for uploading custom syllabus data

- **Interactive Dashboards**

  - Curriculum risk distribution

- **Clear Alignment Categories**
  - High Alignment  
  - Partial Alignment  
  - Low Alignment  

- **Curriculum Risk Metrics**
  - Percentage of low-alignment industry roles  
  - Average syllabus match score  

- **Modern User Interface**
  - Dark-themed layout  
  - Glassmorphic styling  
  - Clean and professional design  

- **Exportable Analysis**
  - Downloadable reports for further evaluation and documentation  

---

## 🧠 Conceptual Workflow

1. Academic syllabus content and industry job descriptions are collected  
2. Text data is cleaned and normalized using NLP techniques  
3. Content is converted into numerical representations  
4. Similarity scores are computed to measure alignment  
5. Results are categorized, visualized, and summarized  
---

## 📊 Alignment Interpretation

- **High Alignment**  
  Strong overlap between curriculum and job requirements  

- **Partial Alignment**  
  Moderate overlap, indicating scope for improvement  

- **Low Alignment**  
  Significant skill gaps requiring curriculum updates  

These metrics enable institutions to prioritize curriculum enhancements based on industry relevance.
